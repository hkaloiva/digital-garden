# Automation should remove toil, not judgment

Rule of thumb I'm developing: **automate the boring, keep the judgment.**

## What to automate

- Repetitive data entry, file moves, status updates
- Reminders and follow-ups
- Report generation from existing data
- Routine comms (acknowledgements, receipts)

## What NOT to automate

- Client-facing judgment calls
- Anything where context changes the answer
- Relationships and trust-building
- Decisions with real downside

## The test

If automating it would make a client feel like they're talking to a machine, don't. If it frees me up to be more present where it matters, do.
